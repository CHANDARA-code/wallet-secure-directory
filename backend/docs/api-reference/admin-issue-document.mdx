---
title: "Issue document"
api: "POST /api/admin/documents"
description: "Issue a new identity document to a user."
authMethod: "bearer"
---

Requires admin role (`session.user.role === 'admin'`). Validates `data` strictly (unknown keys rejected). Real calendar dates required and `expiryDate` must be after `issueDate`. Returns `404` if `userId` is unknown, and `400` with field messages if payload is invalid.

<ParamField body="userId" type="string" required>
  Target user ID.
</ParamField>
<ParamField body="type" type="string" required>
  Document type (`driving_license`).
</ParamField>
<ParamField body="data" type="object" required>
  Identity payload. For `driving_license`, requires `fullName`, `dateOfBirth`, `address`, `nationality`, `issuingAuthority`, `licenseClasses`, `restrictions`, `issueDate`, and `expiryDate`.
</ParamField>
