---
title: "List documents (Admin)"
api: "GET /api/admin/documents"
description: "List all identity documents with optional user filter."
authMethod: "bearer"
---

Requires admin role (`session.user.role === 'admin'`). Returns `403` for non-admin users and `401` for unauthenticated requests.

<ParamField query="limit" type="number" default="20">
  Number of results to return (between 1 and 100).
</ParamField>
<ParamField query="offset" type="number" default="0">
  Result offset (0 or greater).
</ParamField>
<ParamField query="userId" type="string">
  Filter documents by user ID.
</ParamField>
