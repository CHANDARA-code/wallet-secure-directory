---
title: "Revoke document"
api: "POST /api/admin/documents/:id/revoke"
description: "Revoke an issued identity document. Idempotent."
authMethod: "bearer"
---

Requires admin role (`session.user.role === 'admin'`). Revoking an already-revoked document is idempotent. Returns `404` if document ID is not found.

<ParamField path="id" type="string" required>
  Document unique identifier.
</ParamField>
